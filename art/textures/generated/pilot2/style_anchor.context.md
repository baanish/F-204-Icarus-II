# Style anchor for the pilot

This is a one metre square material sample for the F-204 Icarus II, a modernised F-104 Starfighter interceptor in Primeva PALA service. It establishes paint grain, narrow panel joints, flush fastener scale and restrained wear. It is not an aircraft UV island and will never be projected directly onto the aircraft. All later part calls receive this same image as a style reference.

The sample has one straight joint and a sparse flush fastener row. The joint illustrates treatment only. Actual part guides decide panel locations from the model's frames, spars, control boundaries and access panels. No image references are used for this first call. No game texture is read or provided.

Requested image: 1536 square for 1 x 1 metre, 1536 px/m. Actual native dimensions and density are recorded after generation.

Actual native output: 1254 x 1254, 1254 px/m for the one metre square. This is a scale reference, not an atlas island.

Shared style block:
Clean modernised F-104 interceptor in Primeva PALA service. Maintained aircraft, believable restrained service wear, crisp flush construction. Flat diffuse albedo only, neutral medium grey paint, no directional lighting, no highlights, shadows, ambient occlusion, perspective, bevel shading or painted dents. Fine satin paint grain and tiny handling scuffs. Recessed joints are narrow charcoal lines, not black trenches. Fasteners are small and sparse, flush heads in orderly structural rows. No random greebles, decorative panels, post-apocalyptic wear, rust, exposed machinery, text, markings, insignia or camouflage. The compositor adds scheme colours and decals later. Keep broad colour constant; detail belongs at its true physical scale.
